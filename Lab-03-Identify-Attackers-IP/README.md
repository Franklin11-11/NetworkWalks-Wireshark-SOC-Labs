# Lab 03: Identify the Attacker's IP

## Objective

Investigate network traffic in Wireshark to identify a potentially malicious source IP address using packet-level evidence.

## Tools

* Wireshark
* Kali Linux
* Network packet analysis

## Investigation Method

1. Opened the lab packet capture in Wireshark.
2. Examined network conversations and source/destination IP addresses.
3. Used packet details and traffic patterns to investigate the potentially suspicious host.
4. Intended to identify the suspected source and document supporting evidence.

## Security Recommendations

* Investigate unusual connections and unexpected communication patterns.
* Correlate suspicious IP addresses with other network and security logs.
* Avoid blocking an IP address solely because it appears unusual; validate the evidence and business context first.
* Preserve relevant packet captures and investigation notes.
